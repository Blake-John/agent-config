# 计划命令

为以下需求创建详细的实现计划：$ARGUMENTS

## 你的任务

1. **重述需求** — 明确需要构建什么
2. **识别风险** — 暴露潜在问题、阻塞项和依赖
3. **创建分步计划** — 将实现拆分为多个阶段
4. **等待确认** — 必须在收到用户批准后才能继续

## 输出格式

### 需求重述
[清晰简明地重述将要构建的内容]

### 实现阶段
[阶段 1：描述]
- 步骤 1.1
- 步骤 1.2
...

[阶段 2：描述]
- 步骤 2.1
- 步骤 2.2
...

### 依赖
[列出外部依赖、API、服务]

### 风险
- HIGH：[可能阻塞实现的关键风险]
- MEDIUM：[需要处理的中等风险]
- LOW：[次要关注点]

### 预估复杂度
[HIGH/MEDIUM/LOW 带时间预估]

**等待确认**：按此计划执行？（是/否/修改）

---

**关键**：在用户明确确认前，不得编写任何代码。
