# 重构清理命令

分析并清理代码库：$ARGUMENTS

## 你的任务

1. **检测死代码** — 使用分析工具
2. **识别重复代码** — 发现合并机会
3. **安全移除** — 未使用的代码并做好记录
4. **验证** — 确保功能不受影响

## 检测阶段

### 运行分析工具

```bash
npx knip            # 查找未使用的导出
npx depcheck        # 查找未使用的依赖
npx ts-prune        # 查找未使用的 TypeScript 导出
```

### 手动检查

- 未使用的函数（无调用者）
- 未使用的变量
- 未使用的导入
- 注释掉的代码
- 不可达代码
- 未使用的 CSS 类

## 移除阶段

### 移除前检查

1. **搜索用途** — grep、查找引用
2. **检查导出** — 可能被外部使用
3. **验证测试** — 没有测试依赖它
4. **记录移除** — git 提交信息

### 安全移除顺序

1. 先移除未使用的导入
2. 再移除未使用的私有函数
3. 再移除未使用的导出函数
4. 再移除未使用的类型/接口
5. 最后移除未使用的文件

## 合并阶段

### 识别重复

- 功能相似的函数
- 复制粘贴的代码块
- 重复的模式

### 合并策略

1. **提取工具函数** — 用于重复逻辑
2. **创建基类** — 用于相似类
3. **使用高阶函数** — 用于重复模式
4. **创建共享常量** — 用于魔数

## 验证

清理后：

1. `npm run build` — 构建成功
2. `npm test` — 所有测试通过
3. `npm run lint` — 无新的 lint 错误
4. 手动冒烟测试 — 功能正常

## 报告格式

```
死代码分析
==========

已移除：
- file.ts: functionName（未使用的导出）
- utils.ts: helperFunction（无调用者）

- formatDate() 和 formatDateTime() → dateUtils.format()

待处理（需要人工审查）：
- oldComponent.tsx：可能未使用
```
