# 代码审查命令

审查代码变更的质量、安全性和可维护性：$ARGUMENTS

## 检查类别

### 安全问题（CRITICAL）

- [ ] 硬编码凭据、API 密钥、令牌
- [ ] SQL 注入漏洞
- [ ] XSS 漏洞
- [ ] 缺少输入校验
- [ ] 不安全的依赖
- [ ] 路径遍历风险
- [ ] 认证/授权缺陷

### 代码质量（HIGH）

- [ ] 函数超过 50 行
- [ ] 文件超过 800 行
- [ ] 嵌套深度超过 4 层
- [ ] 缺少错误处理
- [ ] console.log 语句
- [ ] TODO/FIXME 注释
- [ ] 公共 API 缺少 JSDoc

### 最佳实践（MEDIUM）

- [ ] 修改模式（应使用不可变模式）
- [ ] 不必要的复杂性
- [ ] 新代码缺少测试
- [ ] 可访问性问题
- [ ] 性能问题

### 风格（LOW）

- [ ] 命名不一致
- [ ] 缺少类型标注
- [ ] 格式问题

## 报告格式

每条问题：

```
**[严重级别]** file.ts:123
问题：[描述]
修复：[如何修复]
```

## 决策规则

- **CRITICAL 或 HIGH 问题**：阻止提交，必须修复
- **MEDIUM 问题**：建议合入前修复
- **LOW 问题**：可选改进

---

**重要**：绝不批准有安全漏洞的代码！
