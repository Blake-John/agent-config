# 测试覆盖率命令

分析测试覆盖率并识别缺口：$ARGUMENTS

## 覆盖率目标

| 代码类型 | 目标 |
|---------|------|
| 标准代码 | 80% |
| 金融逻辑 | 100% |
| 认证/安全 | 100% |
| 工具函数 | 90% |
| UI 组件 | 70% |

## 覆盖率改进计划

1. **Critical**（立即添加）
   - [ ] 认证逻辑文件

2. **High**（本轮迭代添加）
   - [ ] 核心业务逻辑文件

3. **Medium**（碰到时添加）
   - [ ] 工具函数文件
