# 学习命令

从当前会话中提取模式、经验和可复用的见解：$ARGUMENTS

## 提取内容

1. **发现的模式** — 反复出现的解决方案或方法
2. **应用的最佳实践** — 效果好的技术
3. **需要避免的错误** — 遇到的问题及解决方案
4. **可复用的片段** — 值得保存的代码模式

## 输出格式

### 发现的模式

**模式：[名称]**
- 上下文：何时使用此模式
- 实现：如何应用
- 示例：代码片段

### 应用的最佳实践

1. [实践名称]
   - 为什么有效
   - 何时应用

### 需要避免的错误

1. [错误描述]
   - 出了什么问题
   - 如何预防

## Instinct 格式

```json
{
  "trigger": "[触发此学习的情境]",
  "action": "[要做什么]",
  "confidence": 0.7,
  "source": "session-extraction"
}
```

**提示**：在长会话期间定期运行 `/learn`，在上下文压缩前捕获见解。
