# 开发工作流技能

## 概述

本工作流指导整个项目开发过程，提供一个全面的框架，确保开发顺利进行。

它应与 `agent-engine` 技能配合使用，以更精细地控制开发过程。

## 何时使用此技能

在以下情况下使用此技能：

- 为 Rust Todo 应用实现新功能
- 修复项目中的 bug
- 用户明确要求遵循开发工作流
- 开始任何需要结构化方法的重要代码变更

## 功能实现流程

```
Research → Design → Implement → Test → Review → Commit
```

## 阶段 1：研究

使用以下工作流进行研究。

### 步骤 1.1 - 代码库研究

- 阅读相关模块中的现有代码
- 检查代码库中的相似模式
- 记录当前行为和数据结构

### 步骤 1.2 - 外部研究（必需）

- 搜索以下内容：
  - 适用于该功能的现有 Rust 库
  - 开源实现（GitHub）
  - 来自 crates.io 的最佳实践
- 筛选并总结发现
- 报告：每条发现说明"有用是因为……"

### 步骤 1.3 - 需求澄清

- 如果功能范围不明确，与用户确认
- 确认边界情况
- 询问："对于这个功能，我的理解是 X。这样对吗？"

---

## 阶段 2：设计

使用以下工作流进行设计。

### 步骤 2.1 - 框架设计

- 设计项目架构和技术栈
- 规划实现结构
- 确定需要修改的文件和函数
- 定义模块之间的接口

### 步骤 2.2 - 框架审查

- 向用户展示设计方案
- 验证设计是否符合功能需求
- 根据反馈进行调整

### 步骤 2.3 - 检查清单

- [ ] 已定义新数据结构
- [ ] 已规划新函数
- [ ] 已确定需要修改的现有代码
- [ ] 已考虑边界情况

## 阶段 5：审查

使用以下工作流进行审查。

### 步骤 5.1 - 代码审查

- 进行彻底的代码审查
- 处理 CRITICAL/HIGH 级别问题
- 尽可能修复 MEDIUM 级别问题

### 步骤 5.2 - 质量检查

- [ ] 无新警告
- [ ] 无硬编码值
- [ ] 注释准确
- [ ] 如有必要，更新 README

---

## 阶段 6：提交

### 提交信息格式

```
<type>: <description>

<optional body>
```

类型：feat, fix, refactor, docs, test, chore, polish

**示例**：

```
feat: implement sort mode with date/urgency options

- Add SortMode to CurrentMode enum
- Sort tasks by due date (asc/desc)
- Sort tasks by urgency (asc/desc)
- Allow manual reorder after sort
```
